# 탭

> 한 줄 정의: 탭은 같은 화면 안에서 관련된 여러 콘텐츠 그룹을 전환해 보여주는 UI 패턴입니다.

## 왜 중요한가

기획자가 "한 페이지 안에서 내용만 바꿔 보여줘"라고 말할 때, 이것이 페이지 이동이 아니라 탭 전환 구조라는 점을 분명히 해야 합니다. 탭이라는 용어가 들어가야 AI IDE가 같은 맥락 안에서 섹션을 바꾸는 패턴으로 이해합니다.

탭은 서로 관련된 하위 정보 그룹을 한 화면 안에서 정리할 때 강합니다.

## 언제 쓰는가

- 상세 정보 / 리뷰 / 문의처럼 관련된 하위 섹션이 있을 때
- 계정 설정처럼 같은 맥락의 여러 하위 패널을 나눌 때
- 정보는 분리하되 페이지 이동까지는 필요 없을 때

## 언제 쓰지 말아야 하는가

- 서로 목적이 완전히 다른 화면일 때
- 탭 수가 너무 많아 한 줄에 담기 어려울 때
- 사용자가 여러 섹션을 동시에 비교해야 할 때

<Callout type="tip" title="탭은 같은 주제 아래 여러 하위 섹션을 전환하는 데 적합합니다">
완전히 다른 기능을 억지로 탭에 넣기보다, 하나의 큰 맥락 아래 묶을 수 있을 때 사용하는 편이 자연스럽습니다.
</Callout>

## 비개발자가 자주 하는 모호한 요청

- "한 화면에서 내용만 바뀌게 해줘"
- "상단 메뉴 눌렀을 때 아래가 바뀌게 해줘"
- "상세 탭 만들어줘"

이 요청에는 탭 제목, 기본 선택 탭, 모바일 처리 방식이 빠져 있습니다.

## 더 좋은 요청으로 바꾸는 방법

- 탭 이름을 먼저 적기
- 기본 선택 탭을 정하기
- 탭 안 콘텐츠 성격을 구분하기
- 모바일에서 가로 스크롤이나 다른 패턴이 필요한지 적기

## 복붙 가능한 프롬프트 예시

### 1. 상품 상세 탭

<PromptCodeBlock>
상품 상세 페이지 상단에 탭 UI를 만들어주세요.
탭은 "상세 정보", "리뷰", "배송 안내" 세 가지로 구성하고, 선택된 탭은 밑줄과 강조 색상으로 표시해주세요.
모바일에서는 탭 수가 많아지면 가로 스크롤되게 해주세요.
</PromptCodeBlock>

### 2. 설정 화면 탭

<PromptCodeBlock>
설정 페이지 상단에 탭 UI를 추가해주세요.
"프로필", "알림", "보안" 탭으로 나누고, 현재 선택된 탭은 URL 상태와 함께 유지되게 해주세요.
탭 전환 시 해당 패널만 바뀌고 페이지 전체는 새로고침되지 않게 해주세요.
</PromptCodeBlock>

### 3. 문서 예시 탭

<PromptCodeBlock>
문서 페이지 안에서 예시 코드를 탭으로 나눠 보여주세요.
"기본 예시", "고급 예시", "실패 예시" 탭을 두고, 각 탭마다 다른 코드 블록이 보이게 해주세요.
현재 탭이 명확히 보이도록 강조 스타일을 넣어주세요.
</PromptCodeBlock>

<Callout type="warning" title="탭 수가 너무 많아지면 다른 구조를 고려하는 편이 좋습니다">
탭이 많아지면 탐색성이 떨어지고 모바일에서 특히 답답해지므로, 아코디언이나 별도 페이지 구조가 더 적절할 수 있습니다.
</Callout>

## 구현 체크리스트

- 기본 선택 탭이 정해져 있는가
- 활성 탭이 시각적으로 구분되는가
- 키보드로 탭 이동이 가능한가
- 모바일에서 넘치면 처리 방식이 있는가
- 탭 안 콘텐츠가 같은 큰 맥락 아래 묶여 있는가

## 자주 헷갈리는 개념 비교

### 탭 vs 아코디언

- 탭: 한 번에 한 그룹을 전환해 본다
- 아코디언: 여러 항목을 접고 펼친다

### 탭 vs 페이지 라우팅

- 탭: 같은 화면 안에서 전환한다
- 페이지 라우팅: URL이 바뀌며 다른 페이지로 이동한다

### 탭 vs 드롭다운

- 탭: 항상 노출된 전환 구조
- 드롭다운: 필요할 때 펼치는 메뉴
