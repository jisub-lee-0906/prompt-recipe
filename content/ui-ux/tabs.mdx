# 탭

## 개념 설명

탭은 서로 관련 있는 여러 콘텐츠 그룹을 같은 화면 안에서 전환해 보여주는 인터페이스입니다. 사용자는 큰 맥락을 유지한 채 특정 하위 섹션만 바꿔 볼 수 있습니다.

## 언제 사용하는지

상세 페이지에서 "정보", "리뷰", "문의"처럼 같은 대상에 대한 서로 다른 콘텐츠를 나눠 보여줄 때 적합합니다.

## 실무 맥락 예시

기획자가 "상품 상세에서 설명과 리뷰를 한 화면 안에서 오가게 하고 싶다"고 말하면 탭 구조로 전달하는 것이 자연스럽습니다.

## AI에게 요청하는 좋은 프롬프트 예시

상품 상세 페이지 상단에 탭 UI를 만들어주세요. 탭은 "상세 정보", "리뷰", "배송 안내" 세 가지로 구성하고, 선택된 탭은 밑줄과 강조 색상으로 표시해주세요.
