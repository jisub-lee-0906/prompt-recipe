# 검색 바

## 개념 설명

검색 바는 사용자가 키워드를 입력해 필요한 콘텐츠를 직접 찾도록 돕는 기본 인터페이스입니다. 탐색 구조를 보완하는 빠른 진입점 역할을 합니다.

## 언제 사용하는지

문서 수가 많거나, 사용자가 원하는 항목을 카테고리보다 검색어로 더 쉽게 찾는 서비스에 적합합니다.

## 실무 맥락 예시

문서 사이트가 커지면 사이드바 탐색만으로는 한계가 생깁니다. 이때 검색 바는 가장 빠른 진입 경로가 됩니다.

<Callout type="info" title="검색 바는 결과 품질이 함께 중요합니다">
입력창만 만드는 것이 아니라, 어떤 기준으로 결과를 보여줄지까지 함께 설계해야 탐색 경험이 좋아집니다.
</Callout>

## AI에게 요청하는 좋은 프롬프트 예시

헤더 오른쪽에 검색 바를 배치해주세요. 사용자가 키워드를 입력하면 제목, 설명, 태그를 기준으로 문서를 빠르게 찾을 수 있게 해주세요.
