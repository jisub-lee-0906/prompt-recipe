# 검색 바

> 한 줄 정의: 검색 바는 사용자가 키워드를 입력해 원하는 콘텐츠를 직접 찾아가는 가장 빠른 탐색 진입점입니다.

## 왜 중요한가

문서 수가 늘어나면 카테고리만으로는 탐색 한계가 빨리 옵니다. 검색 바는 정보 구조를 보완하는 직접 진입 경로입니다. AI IDE에게 "검색창 하나 넣어줘"라고 하면 입력창만 생길 수 있지만, 검색 바라고 명확히 요청하면 대상 필드, 결과 노출, 결과 없음 상태까지 함께 설계할 수 있습니다.

## 언제 쓰는가

- 문서, 상품, 사용자처럼 찾고 싶은 대상을 직접 입력하게 할 때
- 카테고리 탐색보다 빠른 직접 이동이 필요할 때
- 헤더, 목록 상단, 전역 검색 모달에서 진입점을 만들고 싶을 때

## 언제 쓰지 말아야 하는가

- 검색 대상 자체가 너무 적어 굳이 입력 탐색이 필요 없을 때
- 결과 설계 없이 입력창만 두면 오히려 기대만 만들고 실패 경험을 줄 때

<Callout type="info" title="검색 바는 입력창보다 결과 경험이 더 중요합니다">
사용자가 무엇을 입력하면 무엇이 검색되는지, 결과가 어떤 순서로 나오고 없을 때 무엇을 보여줄지가 더 중요합니다.
</Callout>

## 비개발자가 자주 하는 모호한 요청

## 더 좋은 요청으로 바꾸는 방법

검색 바를 요청할 때는 아래를 같이 말해야 합니다.

- 어떤 필드를 검색 대상으로 삼을지
- 최소 입력 길이가 필요한지
- 결과를 어디에 어떻게 보여줄지
- 결과가 없을 때 어떤 안내를 보여줄지
- 키보드만으로도 결과를 탐색할 수 있는지

<PromptCodeBlock>
헤더 오른쪽에 검색 바를 배치해주세요.
사용자가 입력하면 제목, 설명, 태그 기준으로 문서를 검색할 수 있어야 하고, 결과는 키보드로도 이동 가능해야 합니다.
결과가 없을 때는 빈 상태를 보여주세요.
</PromptCodeBlock>

<PromptCodeBlock>
검색어가 2글자 이상일 때만 결과 목록이 열리게 해주세요.
결과 목록에는 문서 제목과 짧은 설명, 카테고리 배지를 보여주고, 항목을 클릭하거나 Enter를 누르면 해당 문서로 이동하게 해주세요.
</PromptCodeBlock>

<PromptCodeBlock>
전역 검색 모달 안에 검색 바를 구현해주세요.
Cmd/Ctrl+K로 열 수 있어야 하고, 사용자가 입력하면 제목, 태그, 설명 기준으로 빠르게 필터링되게 해주세요.
검색 결과가 없을 때는 `검색 결과가 없습니다`라는 문구와 함께 다른 검색어를 시도하라는 안내를 보여주세요.
방향키와 Enter만으로도 결과를 선택할 수 있게 해주세요.
</PromptCodeBlock>

<Callout type="warning" title="검색 바는 입력만 있고 결과 설계가 없으면 실패합니다">
입력 후 아무 반응이 없거나, 제목만 검색되고 설명과 태그는 빠지면 사용자는 검색이 약하다고 느낍니다. 검색 범위와 결과 노출 방식을 함께 정해야 합니다.
</Callout>

<Callout type="tip" title="검색 바는 사용자가 '무엇을 찾을 수 있는지' 먼저 느껴야 합니다">
플레이스홀더, 추천 검색어, 최근 검색, 시작 문서처럼 첫 입력 전에 보여주는 정보도 탐색 품질에 큰 영향을 줍니다.
</Callout>

## 구현 체크리스트

- 검색 대상 필드가 명확한가
- 결과 목록이 키보드로도 이동 가능한가
- 결과가 없을 때 안내가 있는가
- 최소 입력 길이나 디바운스가 필요한가
- 필터 바와 함께 쓸 때 역할이 충돌하지 않는가

## 자주 헷갈리는 개념 비교

### 검색 바 vs 필터 바

- 검색 바는 직접 키워드를 입력합니다.
- 필터 바는 정해진 조건으로 범위를 좁힙니다.

### 검색 바 vs 커맨드 팔레트

- 검색 바는 주로 콘텐츠 탐색에 집중합니다.
- 커맨드 팔레트는 검색과 명령 실행을 함께 다룹니다.

### 검색 바 vs 검색 API

- 검색 바는 화면의 입력 UI입니다.
- 검색 API는 실제 검색 결과를 돌려주는 서버 인터페이스입니다.

### 검색 바 vs 상황 허브

- 검색 바는 사용자가 직접 키워드를 입력해 찾습니다.
- 상황 허브는 사용자가 아직 정확한 단어를 모를 때 추천 경로를 제시합니다.
