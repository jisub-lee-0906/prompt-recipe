# 검색 바

> 한 줄 정의: 검색 바는 사용자가 키워드를 입력해 원하는 콘텐츠를 가장 빠르게 찾도록 돕는 탐색 UI입니다.

## 왜 중요한가

문서 수가 늘어날수록 카테고리 탐색만으로는 한계가 생깁니다. 검색 바는 정보 구조를 보완하는 가장 직접적인 진입점입니다.

## 언제 쓰는가

- 문서 검색
- 상품 검색
- 사용자 검색

## 언제 부족해지는가

- 입력창만 있고 결과 품질이 낮을 때
- 제목만 검색되고 설명과 태그는 제외될 때

<Callout type="info" title="검색 바는 입력창보다 결과 품질이 더 중요합니다">
무엇을 대상으로 검색하고, 어떤 순서로 결과를 보여줄지까지 함께 설계해야 합니다.
</Callout>

<PromptCard
  badPrompt="헤더에 검색창 넣어줘."

/>

<PromptCodeBlock>
헤더 오른쪽에 검색 바를 배치해주세요.
사용자가 키워드를 입력하면 제목, 설명, 태그를 기준으로 문서를 빠르게 찾을 수 있게 해주세요.
키보드로도 결과를 이동할 수 있게 해주세요.
</PromptCodeBlock>

<PromptCodeBlock>
검색 입력값이 2글자 이상일 때만 결과 목록을 열어주세요.
결과가 없으면 빈 상태 메시지를 보여주고, 항목을 선택하면 해당 문서 상세 페이지로 바로 이동하게 해주세요.
</PromptCodeBlock>

<Callout type="tip" title="검색과 필터는 함께 쓰일 때 더 강합니다">
검색은 직접 찾는 경로이고, 필터는 범위를 좁히는 경로입니다.
</Callout>

## 체크리스트

- 제목, 설명, 태그를 함께 검색하는가
- 키보드 이동이 가능한가
- 결과가 없을 때 안내가 있는가
