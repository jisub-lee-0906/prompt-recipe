# 팝오버

> 한 줄 정의: 팝오버는 버튼이나 입력 요소 근처에 붙어서 나타나며, 현재 맥락과 연결된 선택지나 설정을 보여주는 작은 패널입니다.

## 왜 중요한가

기획자가 "버튼 누르면 작은 창 뜨게 해줘"라고 말할 때, 실제로 원하는 것이 팝오버인지 모달인지 구분되지 않는 경우가 많습니다. 이 차이를 잘못 잡으면 화면 흐름이 불필요하게 무거워지거나, 반대로 너무 약한 인터랙션이 됩니다.

팝오버는 현재 맥락을 끊지 않은 채 보조 선택지를 여는 데 강점이 있습니다.

## 언제 쓰는가

- 정렬, 보기 방식 같은 간단한 옵션 설정
- 버튼 근처에서 빠르게 선택지를 열어야 할 때
- 입력 필드 보조 도움말을 가까운 위치에 보여줄 때

## 언제 쓰지 말아야 하는가

- 사용자의 확인이 반드시 필요한 경우
- 경고, 삭제 같은 위험 동작을 처리할 때
- 많은 입력 폼이나 긴 설명을 넣어야 할 때

<Callout type="info" title="팝오버는 현재 맥락을 유지하는 것이 핵심입니다">
화면 전체를 덮는 패턴이 아니라, 사용자가 보던 위치 근처에서 짧은 선택을 돕는 데 맞습니다.
</Callout>

## 비개발자가 자주 하는 모호한 요청

- "아이콘 누르면 작은 패널 열리게 해줘"
- "버튼 눌렀을 때 옵션창 띄워줘"
- "입력창 옆에 설정창 하나 붙여줘"

이 요청에는 열리는 위치, 바깥 클릭 시 닫힘 여부, 내부에 들어갈 액션 수준이 빠져 있습니다.

## 더 좋은 요청으로 바꾸는 방법

- 어떤 요소를 기준으로 열릴지 지정하기
- 바깥 클릭 시 닫는지 정하기
- 내부 내용이 선택 메뉴인지 설명 패널인지 명확히 하기
- 모바일에서 팝오버 대신 다른 패턴이 필요한지 검토하기

<PromptCard
  badPrompt="정렬 버튼 누르면 작은 창 뜨게 해줘."
  goodPrompt="정렬 버튼을 누르면 버튼 아래에 팝오버가 열리게 해주세요. 내부에는 최신순, 인기순, 이름순 옵션을 세로 리스트로 보여주고, 바깥 영역을 클릭하면 닫히게 해주세요. 현재 선택된 정렬 옵션은 체크 표시로 보여주세요."
/>

## 복붙 가능한 프롬프트 예시

### 1. 정렬 팝오버

<PromptCodeBlock>
목록 상단의 정렬 버튼을 누르면 버튼 바로 아래에 팝오버가 열리게 해주세요.
내부에는 최신순, 인기순, 이름순 옵션을 세로로 배치하고, 현재 선택된 항목은 체크 아이콘으로 표시해주세요.
바깥 영역을 클릭하면 닫히게 해주세요.
</PromptCodeBlock>

### 2. 보기 옵션 팝오버

<PromptCodeBlock>
카드 리스트 오른쪽 상단의 보기 옵션 버튼을 누르면 팝오버가 열리게 해주세요.
리스트 보기와 카드 보기 전환, 카드 간격 옵션을 넣어주세요.
팝오버는 현재 버튼 위치를 기준으로 열리고, 선택 즉시 반영되게 해주세요.
</PromptCodeBlock>

### 3. 입력 도움말 팝오버

<PromptCodeBlock>
비밀번호 입력 필드 옆 도움말 아이콘을 누르면 팝오버가 열리게 해주세요.
내부에는 비밀번호 규칙과 예시를 짧게 보여주고, 입력을 가리지 않는 위치에 열리게 해주세요.
필요할 때만 열리고 바깥을 누르면 닫히게 해주세요.
</PromptCodeBlock>

<Callout type="warning" title="팝오버에 위험 액션 확인까지 넣으면 패턴이 어색해집니다">
삭제 확인처럼 중요한 결정을 받는 경우에는 팝오버보다 다이얼로그나 모달이 더 적절합니다.
</Callout>

## 구현 체크리스트

- 기준 요소 근처에 자연스럽게 배치되는가
- 바깥 클릭과 ESC로 닫히는가
- 현재 선택 상태가 드러나는가
- 모바일에서 가리지 않거나 대체 패턴이 있는가
- 내부 내용이 팝오버 크기에 맞게 짧고 명확한가

## 자주 헷갈리는 개념 비교

### 팝오버 vs 툴팁

- 팝오버: 선택지나 상호작용이 들어간다
- 툴팁: 짧은 설명만 보여준다

### 팝오버 vs 모달

- 팝오버: 현재 화면 흐름을 유지한다
- 모달: 현재 흐름을 잠시 멈추고 집중시킨다

### 팝오버 vs 드롭다운

- 팝오버: 더 자유로운 보조 패널 구조
- 드롭다운: 메뉴나 선택지에 더 특화된 패턴
