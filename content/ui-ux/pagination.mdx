# 페이지네이션

## 개념 설명

페이지네이션은 긴 목록을 한 번에 모두 보여주지 않고 여러 페이지로 나누는 방식입니다. 현재 위치와 전체 범위를 함께 제어할 수 있습니다.

## 언제 사용하는지

검색 결과, 게시글 목록, 주문 내역처럼 항목이 많고 특정 페이지로 바로 이동해야 하는 서비스에 적합합니다.

## 실무 맥락 예시

기획자가 "검색 결과가 수백 개 나올 수 있다"고 말하면, 무한 스크롤 대신 페이지네이션이 더 관리하기 쉬운지 먼저 검토해야 합니다.

## AI에게 요청하는 좋은 프롬프트 예시

문서 목록 하단에 페이지네이션 컴포넌트를 만들어주세요. 이전/다음 버튼과 현재 페이지 번호를 표시하고, 현재 페이지는 강조 스타일로 보여주세요.
