# 페이지네이션

> 한 줄 정의: 페이지네이션은 많은 데이터를 일정 단위로 나누고, 사용자가 페이지 번호를 기준으로 이동할 수 있게 만드는 탐색 패턴입니다.

## 왜 중요한가

목록이 길어질수록 사용자는 지금 어디를 보고 있는지, 얼마나 더 볼 수 있는지, 다시 돌아올 수 있는지를 중요하게 느낍니다. AI IDE에게 단순히 "목록 아래 숫자 좀 넣어줘"라고 하는 대신 페이지네이션이라고 정확히 요청하면 URL, 상태 유지, 접근성, 서버 요청 방식까지 더 잘 설계할 수 있습니다.

## 언제 쓰는가

- 검색 결과처럼 결과 수가 많고 특정 위치를 다시 방문해야 할 때
- 관리자 테이블처럼 페이지 번호를 공유하거나 기억해야 할 때
- 서버에서 결과를 잘라서 가져오는 구조가 필요할 때

## 언제 쓰지 말아야 하는가

- 피드형 탐색처럼 자연스럽게 계속 읽는 경험이 더 중요할 때
- 결과 수가 적어서 한 화면에 모두 보여줄 수 있을 때
- 페이지 번호보다 필터링과 검색이 훨씬 더 중요한 화면일 때

<Callout type="warning" title="페이지네이션은 결과 탐색 방식까지 함께 설계해야 합니다">
페이지 번호 UI만 추가한다고 끝나지 않습니다. 현재 페이지를 URL에 반영할지, 뒤로 가기 시 상태를 유지할지, 총 페이지 수를 보여줄지까지 함께 정해야 실제로 사용하기 편합니다.
</Callout>

## 비개발자가 자주 하는 모호한 요청

<PromptCard
  badPrompt="목록이 기니까 페이지 버튼 좀 넣어주세요."
  goodPrompt="문서 목록 하단에 페이지네이션을 추가해주세요. 이전/다음 버튼과 현재 페이지 번호를 보여주고, 현재 페이지는 강조해주세요. 페이지가 많으면 모든 번호를 다 노출하지 말고 중간은 생략 부호로 처리해주세요."
/>

## 더 좋은 요청으로 바꾸는 방법

페이지네이션을 요청할 때는 아래를 함께 말해야 합니다.

- 현재 페이지 상태를 URL에 저장할지
- 총 페이지 수를 보여줄지
- 페이지 수가 많을 때 어떤 방식으로 축약할지
- 모바일에서 버튼 수를 줄일지

<PromptCodeBlock>
문서 목록 하단에 페이지네이션을 추가해주세요.
이전/다음 버튼과 현재 페이지 번호를 보여주고, 현재 페이지는 강조해주세요.
페이지 수가 많을 때는 모든 번호를 다 노출하지 말고 앞뒤 몇 개만 보여주고 중간은 생략 부호로 처리해주세요.
</PromptCodeBlock>

<PromptCodeBlock>
검색 결과 화면에 페이지네이션을 넣어주세요.
현재 페이지 번호를 URL 쿼리로 유지해서 새로고침 후에도 같은 페이지를 다시 볼 수 있게 해주세요.
뒤로 가기를 눌렀을 때도 이전에 보던 검색 결과 위치가 최대한 유지되도록 만들어주세요.
</PromptCodeBlock>

<PromptCodeBlock>
관리자 사용자 목록에 페이지네이션을 추가해주세요.
데스크톱에서는 페이지 번호를 충분히 보여주고, 모바일에서는 이전/다음과 현재 페이지 정보만 간단히 보여주세요.
총 결과 수와 현재 범위도 함께 표시해 `총 240명 중 21-40명`처럼 보이게 해주세요.
</PromptCodeBlock>

<Callout type="tip" title="페이지 번호보다 결과 맥락이 더 중요할 때가 많습니다">
`3 / 12페이지`만 보여주는 것보다 `총 240개 결과 중 41-60개`처럼 범위를 함께 보여주면 사용자가 현재 위치를 더 잘 이해합니다.
</Callout>

## 구현 체크리스트

- 현재 페이지가 명확하게 강조되는가
- 이전/다음 버튼의 비활성 상태가 자연스러운가
- URL과 페이지 상태가 연결되는가
- 페이지 수가 많을 때 UI가 과하게 복잡해지지 않는가
- 모바일에서도 터치 가능한 크기를 유지하는가

## 자주 헷갈리는 개념 비교

### 페이지네이션 vs 무한 스크롤

- 페이지네이션은 위치 기억과 재방문에 강합니다.
- 무한 스크롤은 연속 소비 경험에 강합니다.

### 페이지네이션 vs 더 보기 버튼

- 페이지네이션은 명확한 위치와 페이지 단위를 제공합니다.
- 더 보기 버튼은 순차 탐색에는 가볍지만 특정 위치 재방문에는 약합니다.

### 페이지네이션 vs 필터 바

- 페이지네이션은 탐색 위치를 나눕니다.
- 필터 바는 결과 집합 자체를 줄입니다.
