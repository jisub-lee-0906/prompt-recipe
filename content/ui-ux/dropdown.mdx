# 드롭다운

> 한 줄 정의: 드롭다운은 버튼이나 입력 요소를 기준으로 펼쳐져 여러 선택지나 액션을 보여주는 메뉴 패턴입니다.

## 왜 중요한가

AI IDE에게 "메뉴 열리게 해줘"라고만 요청하면 액션 메뉴, 선택 메뉴, 팝오버가 섞여서 구현되기 쉽습니다. 드롭다운이라는 용어를 정확히 쓰면 기준 요소를 중심으로 펼쳐지는 선택 구조를 더 명확하게 전달할 수 있습니다.

## 언제 쓰는가

- 프로필 메뉴처럼 여러 액션을 묶어 보여줄 때
- 정렬 기준, 상태 필터 같은 선택지를 접어둘 때
- 작은 공간 안에서 보조 메뉴를 열어야 할 때

## 언제 쓰지 말아야 하는가

- 항목 수가 너무 많을 때
- 긴 설명이나 복잡한 인터랙션이 필요한 경우
- 사용자가 여러 선택지를 동시에 비교해야 할 때

<Callout type="warning" title="항목이 많아지면 드롭다운은 금방 읽기 어려워집니다">
너무 많은 선택지를 한 번에 넣으면 검색이나 시트, 다이얼로그 같은 다른 패턴이 더 적합해집니다.
</Callout>

## 비개발자가 자주 하는 모호한 요청

- "프로필 버튼 누르면 메뉴 열리게 해줘"
- "정렬 선택 메뉴 만들어줘"
- "점 세 개 눌렀을 때 옵션 나오게 해줘"

이 요청에는 기준 요소, 항목 수, 닫힘 규칙, 현재 선택 상태가 빠져 있습니다.

## 더 좋은 요청으로 바꾸는 방법

- 어떤 버튼과 연결되는지 적기
- 항목 구성과 순서를 적기
- 바깥 클릭, ESC, 항목 선택 후 닫힘 여부를 정하기
- 현재 선택 상태 표시 여부도 포함하기

/>

## 복붙 가능한 프롬프트 예시

### 1. 프로필 드롭다운 메뉴

<PromptCodeBlock>
프로필 아바타를 클릭하면 드롭다운 메뉴가 열리게 해주세요.
메뉴 항목은 "내 정보", "설정", "로그아웃" 순서로 보여주고, 바깥 영역을 클릭하거나 ESC를 누르면 닫히게 해주세요.
hover와 keyboard focus 상태도 명확하게 보여주세요.
</PromptCodeBlock>

### 2. 정렬 선택 드롭다운

<PromptCodeBlock>
문서 목록 상단에 정렬 드롭다운을 추가해주세요.
"최신순", "제목순", "인기순" 항목을 넣고, 현재 선택된 항목은 체크 아이콘과 강조 스타일로 보여주세요.
선택 직후 목록 정렬이 바뀌고 드롭다운은 닫히게 해주세요.
</PromptCodeBlock>

### 3. 행별 더보기 드롭다운

<PromptCodeBlock>
관리자 테이블 각 행 오른쪽에 더보기 드롭다운을 넣어주세요.
"수정", "복제", "비활성화" 액션을 넣고, 위험한 액션은 시각적으로 구분해주세요.
항목을 선택하면 드롭다운은 닫히고, 필요한 경우 다음 다이얼로그로 이어지게 해주세요.
</PromptCodeBlock>

<Callout type="tip" title="드롭다운은 현재 선택 상태가 보일 때 훨씬 유용합니다">
정렬, 필터, 상태 선택처럼 현재 값이 중요한 경우에는 체크 표시나 강조 색상으로 지금 선택된 항목을 보여주는 편이 좋습니다.
</Callout>

## 구현 체크리스트

- 기준 버튼과 메뉴 정렬이 자연스러운가
- 현재 선택 상태가 보이는가
- 바깥 클릭과 ESC 닫힘 규칙이 있는가
- 키보드로 항목 이동이 가능한가
- 항목 수가 드롭다운에 적절한가

## 자주 헷갈리는 개념 비교

### 드롭다운 vs 팝오버

- 드롭다운: 메뉴나 선택지에 더 특화된 패턴
- 팝오버: 더 자유로운 보조 패널 구조

### 드롭다운 vs 컨텍스트 메뉴

- 드롭다운: 특정 버튼 기준으로 열린다
- 컨텍스트 메뉴: 특정 대상이나 우클릭 맥락에 더 가깝다

### 드롭다운 vs 셀렉트

- 드롭다운: 메뉴 액션까지 포함 가능
- 셀렉트: 값 하나를 선택하는 입력 성격이 더 강하다
