# 드롭다운

## 개념 설명

드롭다운은 기본적으로 접혀 있다가 사용자의 클릭이나 포커스에 따라 펼쳐지는 메뉴입니다. 여러 선택지나 액션을 한 영역에 정리할 수 있습니다.

## 언제 사용하는지

정렬 기준 선택, 프로필 메뉴, 옵션 선택처럼 화면을 복잡하게 만들지 않으면서 여러 항목을 제공하고 싶을 때 사용합니다.

## 실무 맥락 예시

기획자가 "프로필 영역에 로그아웃, 설정, 내 정보 수정 메뉴가 필요하다"고 설명할 때 드롭다운 메뉴로 정리하면 구조가 명확해집니다.

<Callout type="warning" title="드롭다운 안에는 너무 많은 액션을 넣지 마세요">
선택지가 과도하게 많아지면 사용자는 오히려 찾기 어려워집니다.
</Callout>

## AI에게 요청하는 좋은 프롬프트 예시

프로필 아바타를 클릭하면 드롭다운 메뉴가 열리게 해주세요. 메뉴 항목은 "내 정보", "설정", "로그아웃"으로 구성하고, 바깥을 클릭하면 닫히게 해주세요.
