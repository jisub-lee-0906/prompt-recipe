# 브레드크럼

## 개념 설명

브레드크럼은 사용자가 현재 어디에 있는지, 상위 구조가 무엇인지 파악할 수 있게 해주는 경로 표시 UI입니다.

## 언제 사용하는지

카테고리 깊이가 있는 쇼핑몰, 문서 사이트, 관리자 화면처럼 계층 구조가 뚜렷한 서비스에 적합합니다.

## 실무 맥락 예시

문서 사이트에서 사용자가 여러 단계 안쪽 문서를 보고 있을 때 "홈 > 프론트엔드 > 라우팅"처럼 위치를 알려주면 방향 감각을 잃지 않습니다.

<Callout type="tip" title="브레드크럼은 깊은 구조일수록 효과적입니다">
페이지 계층이 얕은 서비스에서는 오히려 정보가 반복적으로 느껴질 수 있습니다.
</Callout>

## AI에게 요청하는 좋은 프롬프트 예시

문서 상세 페이지 상단에 브레드크럼을 추가해주세요. 홈, 카테고리명, 현재 문서 제목 순서로 표시하고, 마지막 항목만 클릭되지 않도록 처리해주세요.
