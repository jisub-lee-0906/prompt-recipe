# 브레드크럼

> 한 줄 정의: 브레드크럼은 사용자가 현재 위치를 잃지 않도록 상위 경로를 단계적으로 보여주는 보조 내비게이션입니다.

## 왜 중요한가

브레드크럼은 화면을 더 예쁘게 만드는 장식이 아니라, 깊은 구조를 가진 서비스에서 "내가 지금 어디 있는지"를 빠르게 이해하게 만드는 장치입니다. 특히 AI IDE에게 문서, 관리자, 설정 화면을 만들라고 요청할 때 브레드크럼을 정확히 지정하면 정보 구조가 훨씬 명확해집니다.

## 언제 쓰는가

- 문서 사이트처럼 카테고리와 상세 페이지가 여러 단계로 이어질 때
- 관리자 화면처럼 목록, 상세, 수정 흐름이 깊을 때
- 전자상거래처럼 카테고리 계층이 분명한 서비스에서 위치 감각이 중요할 때

## 언제 쓰지 말아야 하는가

- 단일 랜딩 페이지처럼 계층 구조가 거의 없을 때
- 탭 전환처럼 같은 레벨 안에서 상태만 바뀌는 화면일 때
- 화면이 매우 단순해서 경로 안내보다 시야를 복잡하게 만들 가능성이 클 때

<Callout type="tip" title="브레드크럼은 깊은 구조일수록 효과가 커집니다">
`홈 > 문서 > UI/UX > 모달`처럼 상위 구조가 분명한 화면에서 특히 유용합니다. 반대로 구조가 얕은 화면에서는 브레드크럼보다 제목과 설명이 더 중요합니다.
</Callout>

## 비개발자가 자주 하는 모호한 요청

브레드크럼이 필요한 상황인데도 아래처럼 너무 뭉뚱그려서 요청하는 경우가 많습니다.

<PromptCard
  badPrompt="상단에 현재 위치가 보이게 해주세요."
  goodPrompt="문서 상세 페이지 상단에 브레드크럼을 추가해주세요. `문서 > UI/UX > 모달`처럼 단계 구조를 보여주고, 마지막 항목은 현재 페이지라 클릭되지 않게 처리해주세요. 중간 단계는 링크로 이동 가능해야 합니다."
/>

## 더 좋은 요청으로 바꾸는 방법

브레드크럼을 요청할 때는 최소한 아래를 함께 말해야 합니다.

- 몇 단계 구조인지
- 어떤 항목까지 링크가 가능한지
- 마지막 항목은 현재 페이지인지
- 모바일에서 줄바꿈 또는 축약이 필요한지

<PromptCodeBlock>
문서 상세 페이지 상단에 브레드크럼을 추가해주세요.
`문서 > UI/UX > 모달`처럼 계층 구조를 보여주고, 마지막 항목은 현재 페이지라 클릭되지 않게 처리해주세요.
이전 단계 항목은 링크로 이동 가능해야 하고, 구분자는 얇은 슬래시 대신 시각적으로 가벼운 chevron 아이콘을 사용해주세요.
</PromptCodeBlock>

<PromptCodeBlock>
관리자 상세 화면 상단에 브레드크럼을 넣어주세요.
예시는 `관리자 > 사용자 관리 > 사용자 상세`입니다.
중간 단계는 모두 링크여야 하고, 모바일에서는 두 줄로 깨지지 않도록 길면 가운데 단계를 축약해주세요.
</PromptCodeBlock>

<PromptCodeBlock>
상품 상세 페이지에 브레드크럼을 추가해주세요.
`홈 > 여성 의류 > 아우터 > 상품명` 구조로 보여주고, 카테고리 단계는 클릭 가능하게 만들어주세요.
SEO 목적이 아니라 사용자 위치 인지 목적이므로 제목보다 과하게 튀지 않게 작고 차분한 스타일로 배치해주세요.
</PromptCodeBlock>

<Callout type="warning" title="브레드크럼은 전체 메뉴를 대체하지 않습니다">
브레드크럼은 현재 위치를 설명하는 보조 장치입니다. 전체 탐색을 맡는 글로벌 내비게이션과 역할이 다르므로, 메뉴를 없애고 브레드크럼만 두는 식으로 설계하면 탐색성이 오히려 나빠질 수 있습니다.
</Callout>

## 구현 체크리스트

- 현재 경로가 실제 정보 구조와 일치하는가
- 마지막 항목은 현재 페이지로 표시되고 클릭되지 않는가
- 중간 단계는 실제 이동 가능한 링크인가
- 모바일에서도 줄바꿈과 넘침이 과하지 않은가
- 제목보다 과하게 시선을 빼앗지 않는가

## 자주 헷갈리는 개념 비교

### 브레드크럼 vs 탭

- 브레드크럼은 현재 위치와 상위 구조를 보여줍니다.
- 탭은 같은 레벨의 섹션을 전환하는 도구입니다.

### 브레드크럼 vs 사이드바

- 브레드크럼은 지금 어디 있는지 설명합니다.
- 사이드바는 어디로 갈 수 있는지 폭넓게 보여줍니다.

### 브레드크럼 vs 페이지 제목

- 페이지 제목은 현재 화면의 핵심 내용을 보여줍니다.
- 브레드크럼은 그 화면이 어디에 속하는지 보여줍니다.
