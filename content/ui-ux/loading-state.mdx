# 로딩 상태

## 개념 설명

로딩 상태는 시스템이 작업 중이라는 사실을 사용자에게 명확히 전달하는 인터페이스입니다. 기다림 자체보다 예측 가능성이 중요합니다.

## 언제 사용하는지

페이지 전환, 데이터 조회, 파일 업로드처럼 즉시 완료되지 않는 작업에서 사용합니다.

## 실무 맥락 예시

기획자가 "문서를 클릭했을 때 잠깐 비어 보이면 어색하다"고 말한다면, 스피너나 스켈레톤을 포함한 로딩 상태가 필요합니다.

<Callout type="info" title="로딩은 기다림보다 예측 가능성이 중요합니다">
사용자는 단순한 대기보다, 지금 어떤 정보가 준비 중인지 알 수 있을 때 더 안정감을 느낍니다.
</Callout>

## AI에게 요청하는 좋은 프롬프트 예시

문서 상세 페이지 로딩 중에는 제목, 본문, TOC 위치를 짐작할 수 있는 스켈레톤 UI를 보여주세요. 데이터가 준비되면 자연스럽게 실제 콘텐츠로 교체해주세요.
