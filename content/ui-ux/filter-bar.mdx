# 필터 바

## 개념 설명

필터 바는 목록이나 검색 결과를 조건별로 좁혀 볼 수 있도록 여러 선택 컨트롤을 한 곳에 모아 둔 영역입니다.

## 언제 사용하는지

문서 목록, 상품 목록, 관리자 테이블처럼 결과가 많고 사용자가 원하는 범위를 빠르게 좁혀야 할 때 적합합니다.

## 실무 맥락 예시

기획자가 "태그와 카테고리로 문서를 빨리 걸러 보고 싶다"고 말하면, 상단 필터 바 구조로 요구사항을 정리할 수 있습니다.

## AI에게 요청하는 좋은 프롬프트 예시

문서 목록 상단에 필터 바를 추가해주세요. 카테고리, 태그, 난이도 기준으로 결과를 좁힐 수 있게 하고, 현재 선택된 필터는 칩 형태로 보이게 해주세요.
