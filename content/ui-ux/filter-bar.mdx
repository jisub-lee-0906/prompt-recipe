# 필터 바

> 한 줄 정의: 필터 바는 사용자가 조건을 선택해 결과 목록 범위를 빠르게 좁힐 수 있게 해주는 컨트롤 묶음입니다.

## 왜 중요한가

문서나 상품이 많아질수록 사용자는 전체를 보는 것보다 조건으로 좁혀 보는 방식을 선호합니다.

## 언제 쓰는가

- 카테고리 필터
- 태그 필터
- 가격대나 난이도 필터

## 언제 부족해지는가

- 현재 선택 상태가 보이지 않을 때
- 초기화 방법이 없을 때

<Callout type="tip" title="필터 바는 현재 선택 상태가 명확해야 합니다">
무엇이 적용되었는지 바로 보여주지 않으면 결과가 왜 바뀌었는지 이해하기 어렵습니다.
</Callout>

<PromptCard
  badPrompt="필터 좀 넣어줘."
  goodPrompt="문서 목록 상단에 필터 바를 추가해주세요. 카테고리, 태그, 난이도 기준으로 결과를 좁힐 수 있게 하고, 현재 선택된 필터는 칩 형태로 보이게 해주세요. 초기화 버튼도 함께 제공해주세요."
/>

<PromptCodeBlock>
문서 목록 상단에 필터 바를 추가해주세요.
카테고리, 태그, 난이도 기준으로 결과를 좁힐 수 있게 하고, 현재 선택된 필터는 칩 형태로 보이게 해주세요.
초기화 버튼도 함께 제공해주세요.
</PromptCodeBlock>

<PromptCodeBlock>
상품 목록 상단에 필터 바를 만들어주세요.
브랜드, 가격대, 재고 여부를 필터링할 수 있게 하고, 선택된 필터는 상단에 요약 칩으로 보여주세요.
</PromptCodeBlock>

<Callout type="warning" title="필터가 많아지면 드로어나 시트로 분리하는 편이 낫습니다">
모든 조건을 한 줄에 억지로 넣으면 화면이 쉽게 복잡해집니다.
</Callout>

## 체크리스트

- 현재 적용된 필터가 보이는가
- 초기화 경로가 있는가
- 모바일에서 레이아웃이 무너지지 않는가
