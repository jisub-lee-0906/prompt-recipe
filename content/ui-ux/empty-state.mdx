# 빈 상태

## 개념 설명

빈 상태는 목록이나 화면에 표시할 데이터가 없을 때 단순히 비워 두지 않고, 현재 상황과 다음 행동을 설명하는 UI입니다.

## 언제 사용하는지

검색 결과 없음, 즐겨찾기 없음, 첫 프로젝트 생성 전 화면처럼 사용자가 무엇을 해야 할지 막막할 수 있는 상황에 적합합니다.

## 실무 맥락 예시

기획자가 "처음 들어온 사용자는 아무 것도 없는 화면을 보게 된다"고 말하면, 안내 문구와 시작 버튼을 넣은 빈 상태 설계가 필요합니다.

<Callout type="tip" title="빈 상태에는 다음 행동이 꼭 들어가야 합니다">
설명만 있고 행동 유도가 없으면 사용자는 무엇을 해야 할지 쉽게 놓칩니다.
</Callout>

## AI에게 요청하는 좋은 프롬프트 예시
