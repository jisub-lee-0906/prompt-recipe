# 롤백

> 한 줄 정의: 롤백은 새 기능이나 변경 사항 배포 후 문제가 발생했을 때 이전의 안정된 상태로 신속하게 되돌리는 운영 전략입니다.

## 왜 중요한가

배포는 성공보다 실패 대응이 더 중요할 때가 많습니다. 새 기능이 실제 사용자 환경에서 문제를 만들면, 원인을 분석하는 동안 서비스 영향이 커질 수 있습니다. AI IDE에게 "문제 생기면 되돌릴 수 있게 해줘"라고만 말하면 추상적인 조언으로 끝나기 쉬워서 무엇을 어디까지 되돌릴지, 어떤 조건에서 롤백할지 함께 정의해야 합니다.

## 언제 쓰는가

- 신규 기능, 결제 흐름, 권한 정책처럼 장애 영향이 큰 변경을 배포할 때
- 데이터 구조나 API 응답 계약이 바뀌는 위험한 배포일 때
- 기능 플래그만으로는 문제를 완전히 차단하기 어려울 때

## 언제 쓰지 말아야 하는가

- 되돌릴 자산이 무엇인지 정리되지 않은 상태에서 막연히 롤백만 믿을 때
- 데이터 마이그레이션처럼 단순 코드 되돌리기로 해결되지 않는 변경일 때
- 롤백 조건과 책임자가 없어 실제 상황에서 판단이 늦어질 때

<Callout type="tip" title="롤백은 배포 후 만드는 것이 아니라 배포 전에 준비해야 합니다">
롤백 절차가 문서화되어 있고, 필요한 경우 기능 플래그나 이전 배포본 전환이 가능한 상태여야 실제로 빠르게 대응할 수 있습니다.
</Callout>

## 비개발자가 자주 하는 모호한 요청

<PromptCard
  badPrompt="문제 생기면 롤백 가능하게 해주세요."
  goodPrompt="회원가입 개편 배포 후 심각한 오류가 발생하면 즉시 이전 안정 버전으로 되돌릴 수 있게 롤백 전략을 준비해주세요. 어떤 조건에서 롤백할지, 기능 플래그로 막을 수 있는지, 데이터 영향은 없는지까지 같이 정리해주세요."
/>

## 더 좋은 요청으로 바꾸는 방법

롤백을 요청할 때는 아래를 같이 말해야 합니다.

- 어떤 변경이 배포되는지
- 롤백 트리거가 되는 장애 수준이 무엇인지
- 코드, 설정, 데이터 중 무엇을 되돌릴 수 있는지
- 기능 플래그, 이전 배포본, 백업 중 어떤 수단을 쓸지

<PromptCodeBlock>
결제 플로우 개편 배포용 롤백 전략을 정리해주세요.
결제 성공률 급감, 중복 결제, 결제 완료 후 주문 누락 같은 심각한 문제가 발생하면
어떤 순서로 기능 플래그 차단, 이전 버전 배포, 운영 공지까지 진행할지 체크리스트 형태로 정리해주세요.
</PromptCodeBlock>

<PromptCodeBlock>
관리자 권한 정책 변경 배포 전에 롤백 계획을 세워주세요.
권한 차단 오류가 발생하면 이전 정책으로 빠르게 되돌릴 수 있어야 하고,
되돌리는 동안 로그와 감사 이력은 유지되게 해주세요.
</PromptCodeBlock>

<PromptCodeBlock>
검색 인덱스 개편 배포 후 결과 품질이나 응답 속도가 크게 나빠지면
기존 인덱스 버전으로 즉시 전환할 수 있게 롤백 설계를 제안해주세요.
트래픽 차단 없이 전환하는 방법과 확인 지표도 같이 정리해주세요.
</PromptCodeBlock>

<Callout type="warning" title="데이터 변경은 코드 롤백만으로 해결되지 않을 수 있습니다">
삭제나 구조 변경이 이미 반영된 데이터는 앱 버전만 되돌려도 복구되지 않을 수 있습니다. 데이터 백업과 복구 전략을 별도로 봐야 합니다.
</Callout>

## 구현 체크리스트

- 롤백 조건이 정의되어 있는가
- 되돌릴 대상이 코드, 설정, 데이터 기준으로 구분되어 있는가
- 기능 플래그 또는 이전 배포본 전환 수단이 있는가
- 운영 알림과 확인 지표가 정리되어 있는가
- 데이터 변경 시 복구 계획이 별도로 있는가

## 자주 헷갈리는 개념 비교

### 롤백 vs 기능 플래그

- 기능 플래그는 기능 노출을 끄는 빠른 제어 장치입니다.
- 롤백은 이전 안정 상태 전체로 되돌리는 대응 전략입니다.

### 롤백 vs 폴백

- 롤백은 배포 단위로 되돌리는 운영 대응입니다.
- 폴백은 특정 기능 실패 시 대체 동작을 제공하는 제품 설계입니다.

### 롤백 vs 실패 시나리오

- 실패 시나리오는 어떤 문제가 생길 수 있는지 미리 정리합니다.
- 롤백은 그중 심각한 문제 발생 시 실제로 되돌리는 실행 계획입니다.
