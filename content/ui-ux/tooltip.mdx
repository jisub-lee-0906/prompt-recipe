# 툴팁

## 개념 설명

툴팁은 사용자가 어떤 요소 위에 마우스를 올리거나 포커스를 두었을 때 짧은 설명을 보여주는 인터페이스입니다. 공간을 적게 쓰면서도 의미를 보완할 수 있습니다.

## 언제 사용하는지

아이콘 버튼, 약어, 익숙하지 않은 기능처럼 맥락을 조금 더 설명해야 할 때 적합합니다.

## 실무 맥락 예시

디자이너가 "아이콘만 두면 의미가 애매할 것 같다"고 말한다면, 버튼 옆에 긴 설명을 붙이기보다 툴팁으로 보조하는 방식을 고려할 수 있습니다.

## AI에게 요청하는 좋은 프롬프트 예시

상단 액션 바의 공유 아이콘 위에 마우스를 올리면 "링크 복사"라는 툴팁이 나타나게 해주세요. 툴팁은 요소 바로 위에 배치하고, 어두운 배경과 둥근 모서리 스타일을 적용해주세요.
