# 토스트

## 개념 설명

토스트는 사용자의 작업을 방해하지 않으면서 결과를 짧게 알려주는 메시지입니다. 저장 완료, 복사 성공, 오류 발생처럼 즉시 확인만 필요할 때 사용합니다.

## 언제 사용하는지

토스트는 사용자가 이미 요청한 액션의 결과를 알려줄 때 적합합니다. 별도 확인 버튼 없이도 맥락이 유지되어야 하는 상황에서 유용합니다.

### 사용 시 주의점

중요한 의사결정이 필요한 경고에는 토스트를 쓰면 안 됩니다. 사용자가 반드시 읽고 선택해야 하는 메시지는 모달이나 인라인 경고가 더 적합합니다.

## 실무 맥락 예시

기획자가 "복사 버튼을 눌렀을 때 바로 성공 여부를 알려 달라"고 말한다면, 화면 전체를 막는 팝업보다 자동으로 사라지는 토스트가 더 자연스럽습니다.

## AI에게 요청하는 좋은 프롬프트 예시

프롬프트 복사 버튼을 누르면 우측 상단에 토스트가 나타나게 해주세요. 메시지는 "프롬프트가 복사되었습니다."로 표시하고, 약 2초 뒤 자동으로 사라지게 해주세요. 복사 실패 시에는 오류 토스트를 따로 보여주세요.
