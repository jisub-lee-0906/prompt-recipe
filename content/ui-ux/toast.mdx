# 토스트

> 한 줄 정의: 토스트는 사용자의 작업 흐름을 끊지 않으면서 결과를 짧게 알려주는 비차단형 피드백 UI입니다.

## 왜 중요한가

AI IDE에게 "알림 띄워줘"라고만 요청하면 종종 모달처럼 과한 UI가 나오거나, 반대로 너무 눈에 띄지 않는 텍스트만 붙는 경우가 있습니다. 토스트는 "짧고, 자동으로 사라지고, 현재 맥락을 방해하지 않는 결과 피드백"이라는 점이 핵심입니다.

## 언제 쓰는가

- 복사 성공
- 저장 완료
- 설정 반영 완료
- 짧은 실패 안내

이처럼 사용자가 이미 요청한 행동의 결과를 알려줄 때 가장 적합합니다.

## 언제 쓰지 말아야 하는가

- 사용자가 반드시 읽고 선택해야 하는 경고
- 복구 불가 같은 고위험 안내
- 여러 줄의 긴 설명

이런 경우는 [모달](/docs/ui-ux/modal)이나 인라인 경고가 더 적합합니다.

<Callout type="tip" title="좋은 토스트는 짧고 즉시 이해됩니다">
문장을 길게 쓰기보다, 무엇이 일어났는지와 다음 상태만 빠르게 전달하는 편이 좋습니다.
</Callout>

## 비개발자가 자주 하는 모호한 요청

- "성공하면 알림 하나 보여줘."
- "저장됐다고 위에 뜨게 해줘."
- "복사되면 메시지 보이게 해줘."

이 요청만으로는 위치, 지속 시간, 성공/실패 스타일 구분, 중복 처리 방식이 빠져 있습니다.

## 더 좋은 요청으로 바꾸는 방법

좋은 요청은 아래 요소를 포함합니다.

- 어느 액션 뒤에 뜨는지
- 어디에 뜨는지
- 얼마나 유지되는지
- 실패 버전과 성공 버전을 구분하는지

<PromptCard
  badPrompt="복사되면 알림 하나 보여줘."
  goodPrompt="프롬프트 복사 버튼을 누르면 우측 상단에 토스트가 나타나게 해주세요. 메시지는 '프롬프트가 복사되었습니다.'로 표시하고, 약 2초 뒤 자동으로 사라지게 해주세요. 복사 실패 시에는 오류 토스트를 따로 보여주세요."
/>

## 복붙 가능한 프롬프트

### 1. 복사 성공/실패 토스트

<PromptCodeBlock>
프롬프트 복사 버튼을 누르면 우측 상단에 토스트가 나타나게 해주세요.
메시지는 "프롬프트가 복사되었습니다."로 표시하고, 약 2초 뒤 자동으로 사라지게 해주세요.
복사 실패 시에는 오류 토스트를 따로 보여주고, 성공 토스트와 시각적으로 구분되게 해주세요.
</PromptCodeBlock>

### 2. 저장 완료 토스트

<PromptCodeBlock>
설정 저장이 성공하면 토스트를 보여주세요.
메시지는 "설정이 저장되었습니다."로 표시하고, 저장 중에는 버튼을 비활성화해주세요.
저장 실패 시에는 "다시 시도해주세요."라는 오류 토스트를 따로 보여주세요.
</PromptCodeBlock>

<Callout type="warning" title="토스트는 쌓이는 방식도 중요합니다">
같은 이벤트가 반복될 때 토스트가 과도하게 여러 개 쌓이면 오히려 사용자를 방해할 수 있습니다.
</Callout>

## 구현 체크리스트

- 성공과 실패 토스트가 시각적으로 구분되는가
- 너무 오래 남아 있지 않은가
- 위치가 다른 UI를 가리지 않는가
- 반복 이벤트가 발생해도 과도하게 쌓이지 않는가

## 자주 헷갈리는 개념

### 토스트 vs 모달

- 토스트: 결과 전달
- 모달: 결정 유도

### 토스트 vs 인라인 메시지

- 토스트: 일시적인 전역 피드백
- 인라인 메시지: 특정 입력창이나 섹션에 붙는 로컬 피드백
