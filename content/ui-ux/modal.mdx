# 모달

## 개념 설명

모달은 사용자의 현재 작업 흐름 위에 겹쳐서 나타나는 인터페이스입니다. 중요한 확인, 추가 입력, 경고 메시지처럼 즉시 반응이 필요한 상황에서 사용합니다.

## 언제 사용하는지

모달은 사용자의 시선을 잠시 멈추고 특정 행동을 유도해야 할 때 적합합니다. 삭제 확인, 결제 확인, 상세 설정 입력처럼 현재 문맥을 유지한 채 짧은 상호작용이 필요한 경우에 주로 씁니다.

### 사용 시 주의점

너무 많은 필드를 넣으면 사용자가 맥락을 잃기 쉽습니다. 긴 작업 흐름은 별도 페이지나 단계형 폼으로 분리하는 편이 낫습니다.

<Callout type="warning" title="모달은 정말 필요한 순간에만 쓰세요">
사용자가 반드시 확인하거나 입력해야 하는 상황이 아니라면, 토스트나 인라인 피드백이 더 자연스러울 수 있습니다.
</Callout>

## 실무 맥락 예시

예를 들어 서비스 기획자가 "삭제는 되돌릴 수 없다는 점을 명확하게 보여 달라"고 요청할 때, 개발자에게는 단순 팝업이 아니라 배경 dim, 닫기 동작, 포커스 이동까지 포함한 모달로 전달해야 의도가 정확해집니다.

## 체크리스트

- 배경이 어둡게 dim 처리되는지
- 키보드 포커스가 모달 안에 머무는지
- 닫기 버튼과 취소 버튼의 역할이 분리되는지
- 위험한 액션 버튼이 충분히 강조되는지

```text
모달 컴포넌트를 만들 때는 접근성 속성, 포커스 이동, 닫기 동작을 함께 고려해주세요.
```
