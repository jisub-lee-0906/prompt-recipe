# 에러 상태

## 개념 설명

에러 상태는 단순히 실패를 알리는 것이 아니라, 왜 문제가 생겼는지와 사용자가 무엇을 할 수 있는지를 안내하는 UI입니다.

## 언제 사용하는지

데이터 로딩 실패, 저장 실패, 권한 없음처럼 정상 흐름이 끊겼을 때 사용합니다.

## 실무 맥락 예시

기획자가 "문서 목록을 불러오지 못했을 때 빈 화면이면 안 된다"고 말한다면, 재시도 버튼과 설명 문구가 있는 에러 상태를 설계해야 합니다.

<Callout type="warning" title="에러 상태는 사용자를 탓하지 않아야 합니다">
실패 원인을 설명하되, 사용자가 취할 수 있는 다음 행동을 같이 제시하는 것이 중요합니다.
</Callout>

## AI에게 요청하는 좋은 프롬프트 예시
