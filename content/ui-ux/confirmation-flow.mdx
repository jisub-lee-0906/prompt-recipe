# 확인 흐름

## 개념 설명

확인 흐름은 사용자의 실수를 줄이기 위해 중요한 행동 직전에 한 번 더 의도를 묻는 UX 패턴입니다.

## 언제 사용하는지

삭제, 탈퇴, 결제, 게시 전송처럼 되돌리기 어렵거나 비용이 발생하는 행동에 적합합니다.

## 실무 맥락 예시

기획자가 "탈퇴는 정말 신중해야 한다"고 말한다면, 단순 버튼 클릭 한 번이 아니라 단계적인 확인 흐름으로 설계하는 편이 안전합니다.

<Callout type="warning" title="확인은 자주보다 정확하게 쓰는 것이 중요합니다">
모든 행동에 확인 단계를 넣으면 사용자 피로가 커지고, 정말 중요한 경고의 힘도 약해집니다.
</Callout>

## AI에게 요청하는 좋은 프롬프트 예시

사용자 계정 삭제 전에 확인 흐름을 추가해주세요. 첫 단계에서는 일반 확인 모달을 보여주고, 두 번째 단계에서는 복구 불가 메시지를 더 강하게 강조해주세요.
