# 확인 흐름

> 한 줄 정의: 확인 흐름은 사용자의 실수를 줄이기 위해 중요한 행동 직전에 한 번 더 의도를 묻는 설계입니다.

## 왜 중요한가

삭제, 탈퇴, 결제처럼 되돌리기 어려운 행동은 단순 버튼 클릭만으로 끝내면 실수 가능성이 큽니다.

## 언제 쓰는가

- 삭제
- 탈퇴
- 결제 확정
- 복구 불가 작업

## 언제 과하게 쓰면 안 되는가

- 중요하지 않은 일반 액션
- 반복적으로 자주 하는 일상적 작업

<Callout type="warning" title="확인은 자주보다 정확하게 써야 합니다">
모든 행동에 확인 단계를 넣으면 진짜 중요한 경고도 무뎌집니다.
</Callout>

<PromptCard
  badPrompt="삭제 전에 한 번 더 물어봐줘."
  goodPrompt="사용자 계정 삭제 전에 확인 흐름을 추가해주세요. 첫 단계에서는 일반 확인 모달을 보여주고, 두 번째 단계에서는 복구 불가 메시지를 더 강하게 강조해주세요."
/>

<PromptCodeBlock>
사용자 계정 삭제 전에 확인 흐름을 추가해주세요.
첫 단계에서는 일반 확인 모달을 보여주고, 두 번째 단계에서는 복구 불가 메시지를 더 강하게 강조해주세요.
마지막 확인 버튼은 위험 색상으로 처리하고, 취소 경로는 항상 명확하게 보이게 해주세요.
</PromptCodeBlock>

<PromptCodeBlock>
게시글 영구 삭제 전에 확인 다이얼로그를 보여주세요.
삭제 후 복구할 수 없다는 설명과 함께, 취소 버튼과 삭제 버튼을 분리해주세요.
</PromptCodeBlock>

<Callout type="tip" title="중요도가 높을수록 메시지와 버튼 우선순위가 분명해야 합니다">
확인 흐름은 단순 팝업이 아니라 위험도 전달 설계입니다.
</Callout>

## 체크리스트

- 정말 중요한 액션에만 쓰였는가
- 복구 불가 여부가 명확한가
- 취소와 확인 버튼 우선순위가 분명한가
