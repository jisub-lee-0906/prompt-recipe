# 다이얼로그

## 개념 설명

다이얼로그는 사용자와 시스템이 짧은 상호작용을 주고받기 위한 창입니다. 모달과 비슷하지만 특히 확인, 입력, 결정 유도 같은 문맥을 강조할 때 자주 쓰입니다.

## 언제 사용하는지

중요 액션 확인, 이름 입력, 간단한 폼 작성처럼 현재 흐름 안에서 짧은 결정을 내려야 할 때 적합합니다.

## 실무 맥락 예시

기획자가 "새 폴더 이름을 바로 입력받고 싶다"고 요청하면, 별도 페이지 대신 입력 다이얼로그를 생각할 수 있습니다.

## AI에게 요청하는 좋은 프롬프트 예시

새 폴더 만들기 버튼을 누르면 입력 다이얼로그가 열리게 해주세요. 제목은 "새 폴더 만들기"로 표시하고, 폴더 이름 입력창과 취소/생성 버튼을 함께 배치해주세요.
