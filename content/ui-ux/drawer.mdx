# 드로어

## 개념 설명

드로어는 화면의 왼쪽이나 오른쪽에서 슬라이드되며 나타나는 패널입니다. 현재 화면을 완전히 떠나지 않고도 추가 메뉴나 상세 설정을 보여주고 싶을 때 사용합니다.

## 언제 사용하는지

모바일 메뉴, 장바구니 요약, 상세 필터처럼 보조 정보가 필요하지만 전체 페이지 전환까지는 필요하지 않은 상황에서 적합합니다.

## 실무 맥락 예시

기획자가 "모바일에서는 좌측 메뉴를 접어두고 필요할 때만 열고 싶다"고 말하면, 단순 숨김 영역이 아니라 드로어 패턴으로 설명하는 편이 더 정확합니다.

## AI에게 요청하는 좋은 프롬프트 예시

모바일 화면에서 햄버거 버튼을 누르면 왼쪽에서 드로어가 열리게 해주세요. 배경은 어둡게 dim 처리하고, 바깥 영역을 누르거나 닫기 버튼을 누르면 드로어가 닫히게 해주세요.
