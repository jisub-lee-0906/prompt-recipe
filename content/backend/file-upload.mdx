# 파일 업로드

> 한 줄 정의: 파일 업로드는 사용자가 선택한 파일을 서버나 스토리지로 전송하고 그 결과를 처리하는 흐름입니다.

## 왜 중요한가

파일 업로드는 단순 POST 요청보다 훨씬 많은 고려가 필요합니다. 용량 제한, 확장자 검증, 진행 상태, 실패 처리, 업로드 후 미리보기까지 함께 설계해야 합니다. AI IDE에게 "이미지 올리게 해줘"보다 파일 업로드 흐름이라고 설명하는 편이 훨씬 정확합니다.

## 언제 쓰는가

- 프로필 이미지, 첨부 파일, 문서 업로드 기능에서
- 여러 파일 또는 큰 파일 전송이 필요할 때
- 업로드 후 미리보기, 썸네일, 상태 확인이 필요한 경우

## 언제 쓰지 말아야 하는가

- 텍스트만 보내면 되는 단순 폼에서
- 검증과 실패 처리 없이 무작정 업로드만 받을 때
- 업로드 후 결과를 전혀 확인할 수 없게 설계할 때

<Callout type="tip" title="파일 업로드는 검증과 상태 표시가 핵심입니다">
사용자는 파일이 올라가는 중인지, 실패했는지, 어떤 제한 때문에 막혔는지 알고 싶어합니다.
</Callout>

## 더 좋은 요청으로 바꾸는 방법

파일 업로드를 요청할 때는 아래를 같이 말해야 합니다.

- 어떤 파일 형식을 허용할지
- 최대 용량과 개수 제한이 있는지
- 진행 상태와 업로드 후 결과를 어떻게 보여줄지
- 실패 시 재시도나 삭제 경로가 필요한지

업로드 도중 실패한 파일만 다시 시도할 수 있게 해주세요.
</PromptCodeBlock>

<PromptCodeBlock>

처리 중에는 큐 상태나 진행 메시지도 볼 수 있게 해주세요.
</PromptCodeBlock>

<Callout type="warning" title="파일 업로드는 성공보다 실패 경험 설계가 더 자주 드러납니다">
용량 초과, 네트워크 실패, 확장자 오류 같은 문제는 자주 발생합니다. 이때 사용자에게 무엇을 보여줄지 먼저 정해야 합니다.
</Callout>

## 구현 체크리스트

- 허용 형식과 용량 제한이 정의되어 있는가
- 업로드 진행 상태가 보이는가
- 실패 원인이 사용자에게 이해 가능하게 전달되는가
- 여러 파일 업로드 시 상태가 분리되는가
- 업로드 후 미리보기나 후속 처리 흐름이 있는가

## 자주 헷갈리는 개념 비교

### 파일 업로드 vs 폼 제출

- 파일 업로드는 바이너리 전송과 상태 관리가 핵심입니다.
- 폼 제출은 일반 텍스트 입력 수집 중심일 수 있습니다.

### 파일 업로드 vs 큐

- 파일 업로드는 전송 흐름입니다.
- 큐는 업로드 후 후속 처리 작업을 분리하는 데 쓸 수 있습니다.

### 파일 업로드 vs API 에러 응답

- 파일 업로드는 기능 흐름입니다.
- API 에러 응답은 실패 시 반환 형식입니다.
