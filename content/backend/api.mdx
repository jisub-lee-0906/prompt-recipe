# API

## 개념 설명

API는 서로 다른 시스템이 데이터를 주고받는 방법을 정의한 규칙입니다. 프론트엔드는 어떤 주소로 요청을 보내고, 어떤 형식의 응답을 기대해야 하는지를 API 명세로 이해합니다.

## 언제 사용하는지

회원 정보 조회, 게시글 저장, 검색 결과 요청처럼 화면 밖의 데이터를 다뤄야 할 때 API가 필요합니다.

### 사용 시 주의점

단순히 "API 연결"이라고만 요청하면 필요한 메서드, 파라미터, 실패 처리 방식이 빠질 수 있습니다. 요청과 응답 구조를 함께 정의해야 협업이 쉬워집니다.

## 실무 맥락 예시

기획자가 "검색어로 문서를 찾고 싶다"고 말하면, 개발자에게는 검색 입력 UI뿐 아니라 검색 API의 요청 파라미터와 응답 데이터 구조까지 같이 전달하는 것이 좋습니다.

## AI에게 요청하는 좋은 프롬프트 예시

문서 검색 API를 호출하는 함수를 만들어주세요. 검색어 문자열을 받아 `/api/search?q=` 형식으로 요청하고, 성공 시 문서 제목과 설명 배열을 반환하게 해주세요. 실패하면 사용자에게 보여줄 수 있는 오류 메시지도 함께 다뤄주세요.
