# 인증 흐름

## 개념 설명

인증 흐름은 사용자가 누구인지 확인하고, 그 사용자에게 허용된 기능을 구분하는 절차입니다. 로그인, 세션 유지, 로그아웃, 권한 체크가 모두 이 흐름에 포함됩니다.

## 언제 사용하는지

회원 전용 기능이 있거나, 사용자별로 다른 데이터를 보여줘야 하는 서비스라면 인증 흐름을 먼저 설계해야 합니다.

### 사용 시 주의점

로그인 화면만 만든다고 인증이 끝나는 것은 아닙니다. 만료 처리, 보호된 페이지 접근 제한, 오류 상태 같은 예외 흐름도 함께 고려해야 합니다.

## 실무 맥락 예시

기획자가 "로그인한 사용자만 문서를 즐겨찾기할 수 있게 해 달라"고 요청한다면, 버튼 표시 여부뿐 아니라 로그인 유도, 세션 확인, 비로그인 예외 처리까지 포함해 설명해야 합니다.

<Callout type="tip" title="인증 흐름은 예외 상황까지 설계해야 완성됩니다">
로그인 성공뿐 아니라 만료, 로그아웃, 비로그인 접근, 권한 부족까지 함께 봐야 합니다.
</Callout>
