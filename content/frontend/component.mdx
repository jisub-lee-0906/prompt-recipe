# 컴포넌트

## 개념 설명

컴포넌트는 버튼, 카드, 헤더처럼 반복해서 사용할 수 있는 UI 단위입니다. 각 컴포넌트는 고유한 책임과 입력값을 가지며, 조합을 통해 화면 전체를 구성합니다.

## 언제 사용하는지

같은 형태의 UI가 여러 페이지에서 반복되거나, 하나의 UI를 독립적으로 이해하고 수정해야 할 때 컴포넌트로 분리합니다.

### 사용 시 주의점

재사용 가능성을 지나치게 일반화하면 오히려 복잡도가 커질 수 있습니다. 실제로 반복되는 패턴이 있는지 먼저 확인한 뒤 분리하는 것이 좋습니다.

## 실무 맥락 예시

디자이너가 "상품 카드 레이아웃을 여러 화면에서 동일하게 쓰고 싶다"고 요청할 경우, 단순 HTML 복사가 아니라 props 기반 카드 컴포넌트로 설계하라고 전달해야 유지보수가 쉬워집니다.

## AI에게 요청하는 좋은 프롬프트 예시

상품 목록에서 재사용할 수 있는 카드 컴포넌트를 만들어주세요. 썸네일, 제목, 가격, 상태 배지를 props로 받게 하고, 기본 레이아웃은 모바일과 데스크톱 모두에서 자연스럽게 보이도록 구성해주세요.
