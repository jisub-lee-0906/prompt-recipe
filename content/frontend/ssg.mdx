# 정적 사이트 생성

## 개념 설명

정적 사이트 생성은 페이지를 미리 HTML로 만들어 두고 배포하는 방식입니다. 요청마다 서버에서 계산하지 않아도 되어 빠르고 안정적입니다.

## 언제 사용하는지

문서 사이트, 블로그, 마케팅 페이지처럼 자주 바뀌지 않는 콘텐츠를 빠르게 제공해야 할 때 적합합니다.

## 실무 맥락 예시

기획자가 "DB 없이도 문서 사이트를 운영하고 싶다"고 말하면, 로컬 MDX 파일을 기반으로 정적 생성하는 구조가 좋은 선택이 됩니다.

## AI에게 요청하는 좋은 프롬프트 예시

MDX 문서들을 빌드 시점에 정적으로 생성해주세요. `generateStaticParams`를 사용해 모든 문서 경로를 미리 만들고, DB 없이 로컬 파일만 읽어오게 해주세요.
