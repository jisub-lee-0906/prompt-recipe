# Props

## 개념 설명

Props는 컴포넌트 바깥에서 안으로 전달되는 입력값입니다. 같은 컴포넌트 구조를 유지하면서도 다른 데이터와 상태를 표현할 수 있게 해줍니다.

## 언제 사용하는지

버튼의 라벨, 카드의 제목, 모달의 열림 여부처럼 컴포넌트가 외부 값에 따라 달라져야 할 때 사용합니다.

## 실무 맥락 예시

디자이너가 "같은 카드 레이아웃에 문서 제목만 바꿔 여러 개 쓰고 싶다"고 말하면, props 기반 재사용으로 설명하는 것이 적절합니다.

## AI에게 요청하는 좋은 프롬프트 예시

문서 카드 컴포넌트를 만들어주세요. 제목, 설명, 태그 배열, 링크를 props로 받아 재사용할 수 있게 구성해주세요.
