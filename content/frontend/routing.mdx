# 라우팅

## 개념 설명

라우팅은 사용자가 어떤 URL에 접근했는지에 따라 적절한 페이지를 보여주는 방식입니다. 정보 구조와 탐색 경험의 핵심이 됩니다.

## 언제 사용하는지

문서 목록, 상세 페이지, 설정 페이지처럼 서로 다른 화면이 URL 기준으로 구분되어야 할 때 사용합니다.

## 실무 맥락 예시

문서 사이트에서 카테고리와 slug 기반 URL이 필요하다면, 단순 화면 전환이 아니라 라우팅 구조 설계가 먼저 필요합니다.

<Callout type="info" title="좋은 라우팅은 정보 구조를 그대로 드러냅니다">
URL만 봐도 어떤 콘텐츠인지 유추할 수 있으면 사용자와 검색 엔진 모두에게 유리합니다.
</Callout>
