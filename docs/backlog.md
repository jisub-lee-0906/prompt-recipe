# 반복 작업 백로그

## 현재 목표

P1 미작성 문서를 우선 추가하고, 이후 기존 `작성됨` 문서를 `기준 문서` 수준으로 승격합니다.

## 현재 배치

아래 2개는 이번 턴에 추가 완료되었습니다.

- 롤백 `rollback`
- 멱등성 `idempotency`

## 다음 배치 후보

- 전체 96개 기준 문서 완성 후 교차 링크 밀도 점검
- 카테고리 랜딩과 정렬 체계 고도화
- 문서별 비교 표와 체크리스트 표현 통일

## 작업 규칙

- 한 번에 5개 정도씩 추가합니다.
- 추가 후 `npm run build`로 정적 생성 검증을 수행합니다.
- 대표 문서 수준으로 올릴 때는 `writing-standard.md`를 기준으로 보강합니다.
