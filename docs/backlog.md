# 반복 작업 백로그

## 현재 상태

- 전체 문서: `96개`
- 기준 문서: `96개`
- 남은 핵심 과제: `제품 마감`, `검색 UX 고도화`, `운영 자동화`, `인코딩 정리`

## 현재 목표

레퍼런스 사이트를 상용급 문서 제품 수준으로 마감합니다.  
문서 추가보다 탐색 경험, 검색 품질, 메타데이터, 운영 신뢰도를 끌어올리는 단계입니다.

## 이번 라운드

- 검색 결과에 역할 기반 가중치 적용
- 검색 결과에 최근 업데이트일 노출
- 인벤토리 재생성 스크립트 추가
- 프리뷰 스모크 검증 스크립트 추가
- 프리뷰 캡처 자동화 스크립트 추가
- UTF-8 기준 파일 규칙 추가

## 다음 라운드 후보

- 검색 모달 역할별 빠른 필터 칩 고도화
- 홈에 역할별 추천 경로 강조 블록 추가
- 문서 하단 추천 섹션에 “왜 함께 봐야 하는지” 한 줄 이유 추가
- OG 이미지 문구와 색감 미세 조정
- Playwright 캡처 경로를 더 늘려 대표 문서 회귀 검증 강화

## 작업 규칙

- 기능 추가 후에는 `npm run build`, `npm run lint`, `npm run audit:docs`를 기본 검증으로 사용합니다.
- 프리뷰 서버가 떠 있을 때는 `npm run smoke:preview`로 핵심 경로를 빠르게 확인합니다.
- 인벤토리 구조가 흔들리면 `npm run rebuild:inventory`로 다시 생성합니다.
- 시각 회귀가 필요할 때는 `npm run capture:preview`로 대표 경로 스크린샷을 자동 생성합니다.
